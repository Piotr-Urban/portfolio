PROJEKT 01
CV

System rozpoznawania tablic rejestracyjnych

Projekt wykorzystuje zewnętrzne API do analizy obrazu i rozpoznawania tablic rejestracyjnych. Jego ważnym elementem było zaplanowanie przepływu danych: od pobrania obrazu, przez analizę odpowiedzi API, aż po interpretację wyniku i obsługę sytuacji, w których rozpoznanie nie jest jednoznaczne.

obraz API wynik walidacja

Zdobyte doświadczenie

  • integracja zewnętrznego API i obsługa odpowiedzi,
  • przetwarzanie obrazu i analiza wyników,
  • walidacja danych oraz obsługa błędów,
  • testowanie i poprawianie logiki aplikacji.
